# JS Code Analyzer

**JS Code Analyzer** — это мощный инструмент для автоматизированного анализа безопасности JavaScript-кода веб-сайтов. Он позволяет собирать JS-код с указанного URL, выявлять потенциальные уязвимости различных уровней критичности, рассчитывать индекс зараженности и получать интеллектуальные рекомендации по исправлению ошибок с помощью ИИ.

## 🚀 Основные возможности

-   **Сбор кода:** Автоматическое извлечение встроенного (inline) и внешнего JS-кода с веб-страниц.
-   **Форматирование:** Использование `jsbeautifier` для приведения собранного кода к читаемому виду.
-   **Анализ уязвимостей:** Поиск опасных паттернов (eval, XSS, prototype pollution и др.) по пяти уровням критичности (от INFO до BLOCKER).
-   **Математическая оценка:** Расчет показателя зараженности кода на основе плотности уязвимостей.
-   **Интеграция с ИИ:** Получение конкретных советов по безопасности через Gemini API.
-   **История анализов:** Сохранение всех результатов в базе данных PostgreSQL для последующего просмотра.
-   **Интуитивный интерфейс:** Наличие интерактивного TUI-меню (на базе `whiptail`) и классического CLI.

## 🛠 Технологический стек

-   **Язык:** Python 3.10+
-   **Библиотеки:** BeautifulSoup4, HTTPX, Requests, Psycopg2, Rich, JSBeautifier.
-   **База данных:** PostgreSQL.
-   **Интеграции:** Google Gemini API (через OpenAI-совместимый протокол).
-   **Системные зависимости:** `whiptail` (для интерактивного режима в Linux).

### Автоматическая установка зависимостей
Скрипт `run.sh` при запуске проверяет наличие необходимых системных утилит и пытается установить их автоматически, если они отсутствуют. Поддерживаются следующие менеджеры пакетов:
- **APT (Debian, Ubuntu, Mint):** установка `whiptail`.

- **PACMAN (Arch Linux, Manjaro):** установка `libnewt`.

*Примечание: для автоматической установки могут потребоваться права `sudo`.*

## 🔍 Технические детали

### Уровни уязвимостей
Инструмент классифицирует находки по 5 уровням:
-   **L1 (INFO):** Логирование чувствительных данных в консоль.
-   **L2 (MINOR):** Небезопасное хранение в localStorage/sessionStorage.
-   **L3 (MAJOR):** Опасное использование таймеров, потенциальные инъекции в fetch/XHR.
-   **L4 (CRITICAL):** Прямая вставка HTML (innerHTML), использование document.write.
-   **L5 (BLOCKER):** Использование eval(), загрязнение прототипа (Prototype Pollution).

### Формула зараженности (Infection Rate)
Показатель $M$ рассчитывается следующим образом:
$$M = P(A) \times P(B) \times 100\%$$
Где:
-   $P(A) = m_1 / n$ (вероятность того, что строка содержит уязвимость).
-   $P(B) = m_2 / n$ (плотность уязвимостей на строку, ограничено 1.0).
-   $n$ — общее количество содержательных строк кода.
-   $m_1$ — количество строк с уязвимостями.
-   $m_2$ — общее количество найденных уязвимостей.
